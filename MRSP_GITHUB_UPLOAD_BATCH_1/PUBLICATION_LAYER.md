# Publication-layer additions

The authoritative MRSP V1 release files are preserved byte-for-byte where covered by the release manifest. Publication preparation adds `CITATION.cff` and `external_replication/` without rewriting the frozen scientific release.

The strict external-replication kit starts from canonical event rows plus a pre-frozen six-SKU group manifest, reconstructs B1/P1 internally, records input/code hashes, and emits aggregate statistics only. A program execution PASS is not itself a scientific replication claim.

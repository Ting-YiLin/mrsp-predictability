# 在預測之前先判斷可預測性：家庭商品選擇的選擇性預測架構

## 摘要

多數商品選擇研究直接問：「怎樣讓所有事件的預測準確率最高？」本專案最後收斂到另一個問題：**哪些家庭 × 商品事件本來就具有足夠穩定的歷史結構，值得模型作答？**

研究任務是條件式六選一商品選擇：已知家庭這一次會在固定六個 SKU 的商品組中發生購買，預測六個 SKU 中會選哪一個。早期開發顯示，市場先驗 B0 在17,408個前向測試事件中約37.28%，加入家庭歷史的 B1 提升到64.53%。更複雜的 B2 行為融合雖有小幅真實增益，但沒有達到事前設定的3個百分點實用複雜度門檻，因此公開系統保留簡單 B1。

研究後續轉向「可預測性」。P1 是一個沒有學習式係數的家庭穩定度分數，只使用當前事件以前的歷史成熟度、選擇集中度、熵、切換率與近期集中度。公式與三個閾值在開發階段後完全凍結。第一批100個新商品中，P1 得到39.16%覆蓋／76.18%準確率、21.49%／83.55%、11.50%／88.14%。第二批完全不重疊、沒有重新調參的代表樣本（99商品、40,474事件）幾乎逐點重現：41.08%／77.17%、22.00%／84.78%、11.01%／90.06%。另一批跨部門壓力樣本在40.22%覆蓋下達79.33%，而全部事件 B1 為61.18%。

因此目前最有力的結論不是「我們做出一個更複雜的模型」，而是：**可以在結果發生以前，使用非常簡單的家庭穩定度規則篩出值得預測的事件；難以預測的事件可以直接 ABSTAIN（不作答）。**

## 1. 問題定義

目前研究的不是購買發生，也不是下一購物籃，而是：

> 已知家庭本次購買落在一個固定六候選商品組中，預測會選六個 SKU 中的哪一個。

所以「40%覆蓋、77%準確」應解讀成：全部可評估的家庭×商品購買事件中，模型願意對約40%作答；在這些被接受事件中，六選一命中率約77%。

## 2. 研究如何收斂

### 2.1 先修正問題定義

早期曾出現缺可靠時間戳卻解讀成時間狀態、異質 choice set（選擇集合）、先驗不連續、cohort（隊列）邊界錯一位、以及 pooled（合併）效果被單一商品驅動等問題。這些錯誤迫使研究先把時間、選擇集合、先驗與驗證治理修正，再談模型分數。

### 2.2 家庭歷史成為主幹

9商品開發階段兩個前向測試窗合計17,408事件：

| 模型 | 準確率 |
|---|---:|
| B0 市場先驗 | 37.28% |
| B1 家庭歷史 | 64.53% |
| B2 行為融合 | 65.52% |

B1 相對 B0 約 +27.25pp，是主要增量。

### 2.3 複雜度沒有賺到成本

B2 是以 B1 為基礎，再加入上一選擇、repeat streak（重複連續度）、最近選擇份額與距離上次選擇時間等近期行為特徵。在26,659個有家庭歷史事件中，B2 約比 B1 高1.26pp，household/week cluster bootstrap（家庭／星期群聚自助法）都支持方向為正；但仍低於事前3pp門檻，因此保留 B1。

### 2.4 從模型競賽轉向「誰值得預測」

多種 learned router（學習式路由器）、switch specialist（切換專家）、cold-start rescue（冷啟動救援）沒有形成穩定實用提升；相反地，不同事件本身的可預測性差異非常大。因此研究轉向 selective prediction（選擇性預測）。

## 3. B0、B1 與 P1

### B0 市場先驗

```text
other_count_j = max(global_count_j_before_t - household_count_hj_before_t, 0) + 1
B0_j = other_count_j / Σ other_count
```

B0 排除目前家庭自己的歷史，並加1平滑。

### B1 家庭歷史

```text
x_j  = lambda_bin * B0_j + household_count_hj_before_t
B1_j = x_j / Σ x
```

`lambda_bin` 只使用過去 FIT/TUNE 資料，在 `0–2 / 3–9 / 10+` 三個歷史成熟區間選擇。

### P1 家庭穩定度

```text
maturity = clip(log(1+k) / log(21), 0, 1)

core = 0.30*top_share
     + 0.25*(1-normalized_entropy)
     + 0.25*(1-switch_rate)
     + 0.20*recent_concentration

P1 = clip(maturity * core, 0, 1)
```

P1 不使用當前標籤、沒有商品專屬參數，也沒有學習式權重。

凍結閾值：

| 標籤 | P1 cutoff |
|---|---:|
| 0.60 | 0.3608488067 |
| 0.70 | 0.5231119438 |
| 0.80 | 0.6660270792 |

## 4. 泛化與確認設計

新商品候選只能利用 week≤22 的 metadata（中繼資料）與支持度建立。第一批100商品固定後，第二批選樣必須用 stable key（穩定鍵）排除第一批。第二批代表樣本與跨部門壓力樣本彼此不重疊。W3–W6 的結果只能用於評估，不得參與選樣或重新調 P1。

## 5. 核心結果

### 第一批100商品

100選入，99有後期事件，共52,854事件：

| 凍結工作點 | 覆蓋率 | 準確率 |
|---|---:|---:|
| 0.60 | 39.16% | 76.18% |
| 0.70 | 21.49% | 83.55% |
| 0.80 | 11.50% | 88.14% |

### 第二批確認

100選入，99可評估，共40,474事件：

| 凍結工作點 | 覆蓋率 | 準確率 |
|---|---:|---:|
| 0.60 | **41.08%** | **77.17%** |
| 0.70 | **22.00%** | **84.78%** |
| 0.80 | **11.01%** | **90.06%** |

兩批曲線幾乎逐點重現，這是本研究最重要的確認結果。

### 不是少數大商品拉高平均

第二批代表樣本中：

- 0.60：97個活躍商品，93個達到事前目標規則（95.9%）
- 0.70：77個活躍商品，74個達標（96.1%）
- 0.80：34個活躍商品，32個達標（94.1%）

### 跨部門壓力測試

99個可評估商品、36,027事件：

- 全部 B1：61.18%
- P1 選擇性 B1：79.33%
- 覆蓋率：40.22%
- 增益：+18.15pp

至少有5商品的7個部門中，6個通過事前 ≥10pp 的提升門檻。Produce 從80.19%升至88.81%，+8.62pp，方向仍正但沒有通過嚴格10pp規則。

## 6. 為什麼公開失敗歷史

最終簡單架構不是從大量模型中只挑最好看的結果。研究曾明確測試並否定／降級多條路徑，包括錯誤時間狀態、choice-set 問題、cohort off-by-one（隊列錯一位）、被單一商品驅動的 context 效果、無法打敗簡單基準的 router，以及會傷害表現的 hard-case rescue（困難案例救援）。

這些失敗被保留在 `docs/failure_history.md`，目的是讓第三方看見規則如何被證據逐步削減到現在的簡單形式。

## 7. 當前可接受的解讀

目前證據支持：

1. 家庭歷史比市場平均提供大量額外商品選擇資訊；
2. 不同家庭×商品事件在結果發生前就存在很大的可預測性差異；
3. P1 可以把這個差異轉成穩定的 Coverage–Accuracy（覆蓋率－準確率）曲線；
4. ABSTAIN（不預測）不是失敗，而是系統設計的一部分。

這不代表某個家庭在所有商品上都「可預測」或「隨機」。目前的單位是家庭×商品購買事件。

## 8. 證據範圍

最高等級是 `CONFIRMED_WITHIN_PANEL_CROSS_PRODUCT（面板內跨商品確認）`：同一 Complete Journey 資料生態內，規則在不同新商品與不同部門重現。這份發布不包含購買發生預測、下一購物籃預測，也不把 choice set 當成真實貨架即時可得性的完整模型。

原始逐筆交易資料目前不隨發布包重新散布，等待最終資料授權審計。

# 限制與證據範圍

- 任務是條件式六選一 SKU 選擇，不是購買發生或下一購物籃預測。
- Coverage（覆蓋率）是事件覆蓋率，不是不同客戶占比。
- 最強證據是在同一 Complete Journey 資料生態內的跨商品確認；這份發布沒有估計另一零售商／另一消費面板的遷移表現。
- 六選一商品組是 observed substitute proxy（觀察到的替代商品代理），不是即時貨架可得性的完整模型。
- P1 是預測排序分數，不應解讀成因果機制或不可約隨機性的證明。
- 新商品候選生成與確認樣本選擇對 W3–W6 結果保持盲化，但整體資料仍屬觀察性資料。
- 原始交易資料暫不隨發布包重新散布，等待最終授權審計。
- 早期商品曾被反覆研究，因此最終公開主張優先依賴後來兩批互不重疊、P1 完全凍結的新商品證據。

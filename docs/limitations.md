# Limitations and evidence scope

- The task is conditional six-choice SKU selection, not purchase-incidence or next-basket prediction.
- Coverage is event coverage, not unique-customer coverage.
- The strongest evidence is cross-product confirmation inside the same Complete Journey data ecosystem. This release does not estimate transport performance to a different retailer or consumer panel.
- Choice sets are observed six-product substitute proxies, not a complete model of real-time shelf availability.
- P1 is a predictive ranking score. It should not be interpreted as a causal mechanism or proof of irreducible randomness.
- Product groups are constructed from historical metadata/support. The candidate-generation and confirmatory selection are outcome-blind with respect to the evaluation windows, but the broader data-generating environment is observational.
- Raw transaction data are not redistributed in this release pending final licensing review.
- The development history involved repeated analysis of early product sets. Final public claims therefore prioritize the two later non-overlapping new-product batches with frozen P1 rules.
